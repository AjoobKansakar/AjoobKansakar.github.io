## 📌 Overview

This repository contains the source code for my personal website hosted on **GitHub Pages**. It is engineered from scratch without heavy frontend libraries or frameworks to maintain maximum performance, accessibility, and zero external build overhead.

### 🌟 Key Sections

- **Identity:** Brief introduction with social links and quick contact triggers.
- **About Me:** Academic summary (First Class Honours, BSc Computing) and core technical focus.
- **Skills:** Categorized technical competencies spanning Languages, Frameworks, Backend/Databases, and Automation.
- **Experience:** Interactive career timeline detailing software development internship and machine learning data work.
- **Projects:** Highlights of real-world apps including **Jutsu Simulator** (Computer Vision), **KasRrat** (Flutter/Supabase), and **Nepcert** (React/PHP).
- **Certifications:** Direct access to AWS Academy graduate credentials in Machine Learning, NLP, Data Engineering, and Cloud.
